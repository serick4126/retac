# ReTAC（リタック）

ReTAC は、Windows 用ファイラー「卓駆★」（Copyright (C) 1995-2009 COM Corp.。以下、卓駆）の操作感を再現することを目指して作ったファイラーです。キー操作の体系を引き継ぎつつ、卓駆にはなかった Unicode と高 DPI に対応しています。

- 最新版: 3.1.1（2026-10-02）
- 対応環境: Windows 11（日本語環境）
- 実装: .NET 10 / WinForms
- 変更履歴: [CHANGELOG.md](https://github.com/serick4126/retac/blob/main/CHANGELOG.md)
- 外部ツールの設定: [EXTERNAL_TOOLS.md](https://github.com/serick4126/retac/blob/main/EXTERNAL_TOOLS.md)

## 卓駆との関係

ReTAC は、卓駆（正式名称「卓駆★」、Copyright (C) 1995-2009 COM Corp.、開発: 株式会社コム、連絡先: 不明）とは無関係の、独立したソフトウェアです。

- **プログラムの逆アセンブルや逆コンパイルなどのリバースエンジニアリングは行っていません。** 卓駆のプログラムコードは一切使っていません。
- 卓駆にどのような機能があるかを把握するため、次のファイルを調べました。
  - キー設定ファイル（`.KFM`）: キーの割り当て
  - 実行ファイルに含まれる文字列とメニューの定義: コマンドの一覧と機能名
  - ヘルプファイル: 各機能の説明。機能の理解にだけ使い、本文は ReTAC の画面・コード・文書のいずれにも使っていません。
- 調べた結果は、機能の一覧、機能名、メニューの構成、既定のキー割り当ての参考にしました。内部の識別番号として、卓駆のコマンド ID と同じ数値を使っています。動作は卓駆を実際に操作して確かめたうえで、独自に実装しています。
- アイコンや画像など、卓駆に含まれていた画像リソースは一切使っていません。
- 機能名や設定項目名などの文言には、卓駆と同じ名称のものがあります（「ダイレクトジャンプ」「クイックアクセス」など）。いずれもファイラーの一般的な機能を指す名称として使っており、卓駆に固有の表現を写したものではありません。

### ReTAC で新しく作った機能

- Unicode 対応。CP932 で表せない名前のファイルも扱える
- 高 DPI 対応
- 自然順ソート（`file2` が `file10` より前に来る）
- 8 つの表示モード（一覧・詳細・小／中／大／特大アイコン・並べて表示・コンテンツ）。「表示」→「ファイル表示パネル」・コマンド・`Ctrl`+ホイールで切り替える
  - 詳細表示: サイズ・種類・更新日時・作成日時・属性などの列。列の表示と並び、列幅、見出しのクリックでのソート
  - 名前の列の幅の決め方（すべて表示・自動・最大文字数）。省略しても拡張子は残し、全体はツールチップで見せる
  - 中アイコン以上で、画像・動画・PDF などのサムネイル。クラウドのファイルは OS のキャッシュにあるものだけを出し、ダウンロードを始めない
  - 同期状態やショートカットの矢印などの OS の印の重ね表示、マーク用のチェックボックス
  - 空いた所からの投げ縄でのマーク
  - 登録されている拡張子を表示しない設定、拡張子を揃えて表示する設定
- 右ボタンのドラッグ＆ドロップのメニュー（コピー・移動・ショートカットの作成）。ファイル表示パネルの中のフォルダへのドロップ（設定）
- 「パスのコピー」の形（二重引用符で囲んだパス）を、アドレスバーや宛先の欄にそのまま貼り付けられる
- 想定外のエラーの詳細を、実行ファイルと同じフォルダの `retac.error.log` に記録する
- ファイル名を `/` 区切りのパスでコピー
- 外部ツールの自由登録（件数可変）とコマンドマクロ。登録したツールはメニューとポップアップにも並び、すべてにショートカットキーを割り当てられる（[外部ツールの設定](https://github.com/serick4126/retac/blob/main/EXTERNAL_TOOLS.md)）
- 外部ツールの入力ダイアログ。テキスト・フォルダ・ファイル・チェックボックス・ドロップダウンリストを組み合わせ、起動の前の入力を 1 つの画面で済ませる。編集画面では、コマンドラインの読み込み、引数から項目への変換、プレビュー、元に戻すが使える
- 外部ツールキュー（順番に処理し、進行状況の表示と停止ができる）
- マウスのボタン 3／4／5 へのコマンド割り当て（4／5 の既定は「戻る」「進む」）
- インクリメンタルサーチ（`Ctrl`+`F`）。前方一致でカーソルが動く
- ドライブバーの表示切り替え（非表示のときは `L` でドライブを選ぶ）
- 元に戻す（`Ctrl`+`Z`）。名前の変更・移動・コピー・フォルダの作成などを新しい順に 1 回ずつ戻せる
- アドレスバーとパンくず表示。パスの入力、履歴・クイックアクセスからの選択、段やサブフォルダの一覧からの移動ができる
- ブックマークバーとブックマークメニュー。フォルダ・ファイル・コマンド・グループを登録し、管理画面やドラッグで並べ替えられる
- ファイルをブックマークのフォルダやパンくずの各階層へドロップし、確認後にコピー・移動できる
- クイックアクセスにフォルダだけでなく、ファイルとコマンドも登録できる
- 左パネル。ファイルリストの左に、次の 4 つのビューから 1 つを表示する（「表示」メニュー・パネル上端の欄で切り替え。`Tab` でファイルリストと行き来する）
  - ドライブツリー: 今いるドライブのフォルダをツリーで表示する。フォルダを移動すると、ツリーの選択も追従する
  - デスクトップツリー: デスクトップを頂点に、PC・ライブラリ・ネットワークなどをたどる
  - ブックマーク: すべてのブックマークをツリーで表示し、クリック 1 回で実行する。展開したグループは次の起動でも展開したまま
  - プレビュー: カーソル位置のファイルを Windows のプレビュー機能で表示する。プレビューの機能が無い画像はサムネイルを、テキストファイルは内容を表示する
- ツリーへのドラッグ＆ドロップ。ドロップすると、宛先を入れたコピー／移動のダイアログを表示する
- 設定は実行ファイルと同じフォルダの `retac.settings.json` に即時保存（レジストリは使わない）
- アップデータ。ヘルプの「更新を確認」から、新しい版の確認・ダウンロード・入れ替え・再起動までを行う（[更新](#更新)）

## 外部ツール

テキスト エディタ、スクリプト、ターミナル、Git コマンドなど、任意のプログラムを登録して ReTAC から起動できます。

- 登録数に上限はありません。登録したツールはメニューとポップアップメニューに並び、すべてにショートカットキーを割り当てられます。
- 引数にはマクロを書けます。カーソル位置やマークしたファイルのパス、カレントフォルダ、起動の前に入力ダイアログで入れた値などを渡せます。
- 入力ダイアログに並べる項目（テキスト・フォルダ・チェックボックスなど）と、引数を送る順は「入力ダイアログ編集」で設定します。前回の入力を次の初期値にすることもできます。
- マークしたファイルを 1 件ずつ順番に処理できます（外部ツールキュー）。
- 初期状態では、テキスト エディタ・テキスト ビューア（どちらも `notepad.exe`）とターミナル（`cmd.exe`）が登録されています。

**設定画面の説明、マクロの一覧、設定例（エディタ・Python・ターミナル・git）は [EXTERNAL_TOOLS.md](https://github.com/serick4126/retac/blob/main/EXTERNAL_TOOLS.md) にまとめています。**

## インストール

[リリースのページ](https://github.com/serick4126/retac/releases)から zip をダウンロードし、中のファイルをすべて任意のフォルダに展開して `ReTAC.exe` を起動します。`ReTAC.exe` は .NET ランタイムを内包した単一ファイルなので、.NET を別にインストールする必要はありません。設定ファイルは `ReTAC.exe` と同じフォルダに作られます。

### 「Windows によって PC が保護されました」と表示されたとき

ReTAC は個人開発のソフトウェアで、コード署名をしていません。そのため、初回の起動時や新しい版への更新後に、Windows（Microsoft Defender SmartScreen）の「Windows によって PC が保護されました」という画面が表示されることがあります。

[リリースのページ](https://github.com/serick4126/retac/releases)から取った zip であれば、次の手順で起動できます。

1. 画面の「詳細情報」をクリックする。
2. 表示された「実行」ボタンをクリックする。

zip を展開する前にファイルのブロックを解除しておくと、この画面は表示されなくなります。ダウンロードした zip を右クリック →「プロパティ」→「全般」タブの下にある「許可する」にチェックを入れて「OK」を押してから、展開してください。

リリースのページ以外から手に入れたファイルでこの画面が出たときは、実行しないでください。

### 同梱の .NET ランタイムについて

配布する `ReTAC.exe` には、Microsoft の .NET ランタイムが含まれています。このランタイムには、ReTAC の MIT License ではなく、Microsoft .NET Library License（配布物の `DOTNET-LICENSE.txt`）が適用されます。ランタイムに含まれる第三者のソフトウェアの表示は `DOTNET-ThirdPartyNotices.txt` にあります。**ReTAC を使うことで、同梱のランタイムについてはこの使用許諾にも同意したものとみなします。**

アップデータ（`ReTAC.Updater.exe`）はランタイムを同梱していません。Windows に組み込まれている .NET Framework 4.8 で動きます（Windows 11 には必ず入っています）。

自分でビルドする場合は .NET 10 SDK を使います。

```sh
dotnet publish src/ReTAC.App/ReTAC.App.csproj -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:EnableCompressionInSingleFile=true -o publish
dotnet build src/ReTAC.Updater/ReTAC.Updater.csproj -c Release   # アップデータ（bin/Release/net48/ReTAC.Updater.exe）
```

## 更新

ヘルプメニューの「更新を確認」を選ぶか、`ReTAC.Updater.exe` を直接起動します。新しい版があれば確認の画面が表示されます。[更新] を押すと、アップデータが ReTAC を終了し、ファイルを新しい版に入れ替えてから、ReTAC を起動し直します。

- 設定ファイル（`retac.settings.json`）は変更しません。フォルダにあるほかのファイルも削除しません。
- ダウンロードしたファイルは、GitHub が公開している SHA-256 と照合してから使います。
- `Program Files` など、書き込みに管理者権限が必要なフォルダに置いているときは、ファイルを入れ替える前に許可を求めます（UAC）。
- 2.7.1 以前の版にはアップデータが入っていません。アップデータの入った版へは、手動で一度だけ更新してください。

### 通信について

- **ReTAC 本体は、インターネットに一切アクセスしません。** ヘルプの「GitHub のページを開く」はブラウザーでページを開くだけで、通信するのはブラウザーです。登録した外部ツールが通信する場合も、それは外部ツールによるものです。
- インターネットにアクセスするのは、アップデータ（`ReTAC.Updater.exe`）だけです。接続先は GitHub（リリースの情報の問い合わせと、配布用の zip のダウンロード）に限られ、通信するのは「更新を確認」を選んだときだけです。起動時などに自動で確認することはありません。
- セキュリティソフトやファイアウォールの設定によっては、アップデータの通信に許可が要ることがあります。許可できない場合は、ブラウザーで[リリースのページ](https://github.com/serick4126/retac/releases)から zip をダウンロードし、「ReTAC を完全に終了」で ReTAC を終了してから、zip の中のファイルでインストール先を上書きしてください（`retac.settings.json` は zip に入っていないので、上書きされません）。

## 困ったとき

- **左パネルのプレビューで、PDF など特定の種類だけが真っ白のままになる**
  ReTAC が異常終了したり強制終了されたりすると、Windows のプレビュー用のプロセス（`prevhost.exe`）が応答しないまま残ることがあります。
  タスク マネージャーの「詳細」タブで `prevhost.exe` を終了するか、Windows にサインインし直してください。次にプレビューしたときに作り直されます。
  なお、このプロセスはエクスプローラーなどと共有されているため、ReTAC からは終了させません。
