# ReTAC（リタック）

ReTAC は、Windows 用ファイラー「卓駆★」(以下卓駆と記載)の操作感を再現することを目指して作った Windows 向けファイラーです。キー操作の体系を引き継ぎつつ、卓駆にはなかった Unicode と高 DPI に対応しています。

- 最新版: 2.4.0（2026-09-19）
- 対応環境: Windows 11（日本語環境）
- 実装: .NET 10 / WinForms
- 変更履歴: [CHANGELOG.md](CHANGELOG.md)
- 外部ツールの設定: [EXTERNAL_TOOLS.md](EXTERNAL_TOOLS.md)

## 卓駆との関係

卓駆（正式名称「卓駆★」、開発: 株式会社コム、連絡先: 不明）とは無関係の、独立したソフトウェアです。

- **プログラムの逆アセンブルや逆コンパイルなどのリバースエンジニアリングは行っていません。** 卓駆のプログラムコードは一切使っていません。
- 卓駆にどのような機能があるかを把握するため、次のファイルを調べました。
  - キー設定ファイル（`.KFM`）: キーの割り当て
  - 実行ファイルに含まれる文字列とメニューの定義: コマンドの一覧と機能名
  - ヘルプファイル: 各機能の説明。機能を理解するために使用し、本文は ReTAC の画面・コード・文書のいずれにも使っていません
- 調べた結果は、機能の一覧、機能名、メニューの構成、既定のキー割り当ての参考にしました。内部の識別番号として、卓駆のコマンド ID と同じ数値を使っています。動作は卓駆を実際に操作して確かめたうえで、独自に実装しています。
- アイコンや画像など、卓駆に含まれていた画像リソースは一切使っていません。
- 機能名や設定項目名などの文言には、卓駆と同じ名称のものがあります（「ダイレクトジャンプ」「クイックアクセス」など）。いずれもファイラーの一般的な機能を指す名称として使っており、卓駆に固有の表現を写したものではありません。

## 機能

### 卓駆から継承した機能

| 分類 | 機能 |
|---|---|
| ファイル操作 | 開く、フォルダへコピー／移動、削除（ごみ箱経由）、名前の変更、ファイルの連結、属性とタイムスタンプの変更、ショートカットの作成、フォルダの作成 |
| 選択 | マークのトグル（`Space`）、全選択／選択解除、反転選択、同じ拡張子で選択、ワイルドカードで選択 |
| ナビゲーション | 親フォルダ、ルート、前／次のフォルダ、フォルダ履歴、クイックアクセス、ダイレクトジャンプ、ドライブの選択、数字キーでのドライブ移動、デスクトップへ移動 |
| 表示 | ソート（名前・拡張子・サイズ・日付）、最新の情報に更新、表示ファイルタイプの設定、プロパティの表示、ファイル名ジャストフィット（常時有効） |
| クリップボード | コピー／切り取り／貼り付け、ファイル名をコピー（パス付き・名前のみ） |
| 外部連携 | テキスト エディタ・テキスト ビューア・ターミナルの起動、ポップアップメニュー、名前を指定して実行、シェルのコンテキストメニュー |
| 設定 | 配色とフォント、キー割り当て（`Ctrl` 付きを含む）、表示ドライブ、動作環境 |
| ウィンドウ | 常駐（閉じても状態を保つ） |

### 卓駆から継承しなかった機能

| 分類 | 機能 |
|---|---|
| フォルダツリー | フォルダツリーの表示と、それに付随する操作（ツリーの開閉、ツリーとリストの切替、境界の変更） |
| 列表示 | サイズ・日付・属性の列表示。ファイルリストはファイル名だけを表示する |
| 書庫 | 圧縮、書庫の復元、書庫の作成、自己解凍書庫の作成、ISH 変換、書庫ツールの設定 |
| ファイル操作 | ファイルの分割、サブ関連付け実行、関連付けの登録・関連付けで印刷、拡張子／大文字・小文字の一括変換、フォルダ削除の専用コマンド |
| 移動・検索 | 特殊フォルダ（マイ ドキュメントなど）への移動、ネットワーク接続／切断、ドライブ検索、ファイルの検索、フォルダ構成のコピー |
| 表示 | 表示ワイルドカード（絞り込み）、ファイルリスト形式の切替、表示文字の大文字／小文字切替、ファイル情報、ドライブ情報、バイナリダンプ、内蔵ビューア |
| クリップボード | フォルダへ貼り付け、ショートカットを貼り付け、詳細情報付き・UNC 形式のファイル名コピー |
| 設定・ウィンドウ | ポップアップメニューとツールバーの設定、FM 互換モード、付属のキー配列（FD 風・FILMTN 風など）、キー配列の保存、ウィンドウの整列、ホームポジション |
| 陳腐化した機能 | 短いファイル名（8.3 形式）のコピー、ディスク複写／初期化（フロッピー向け）、システム情報、Windows の終了／再起動（いずれも OS の標準機能で足りる） |

### ReTAC で新しく作った機能

- Unicode 対応。CP932 で表せない名前のファイルも扱える
- 高 DPI 対応
- 自然順ソート（`file2` が `file10` より前に来る）
- ファイル名を `/` 区切りのパスでコピー
- 外部ツールの自由登録（件数可変）とコマンドマクロ。登録したツールはメニューとポップアップにも並び、すべてにショートカットキーを割り当てられる（[外部ツールの設定](EXTERNAL_TOOLS.md)）
- 外部ツールキュー（順番に処理し、進行状況の表示と停止ができる）
- マウスのボタン 3／4／5 へのコマンド割り当て（4／5 の既定は「戻る」「進む」）
- インクリメンタルサーチ（`Ctrl`+`F`）。前方一致でカーソルが動く
- ドライブバーの表示切り替え（非表示のときは `L` でドライブを選ぶ）
- 元に戻す（`Ctrl`+`Z`）。名前の変更・移動・コピー・フォルダの作成などを新しい順に 1 回ずつ戻せる
- アドレスバーとパンくず表示。パスの入力、履歴・クイックアクセスからの選択、段やサブフォルダの一覧からの移動ができる
- ブックマークバーとブックマークメニュー。フォルダ・ファイル・コマンド・グループを登録し、管理画面やドラッグで並べ替えられる
- ファイルをブックマークのフォルダやパンくずの段へ落とし、確認後にコピー・移動できる
- クイックアクセスにフォルダだけでなく、ファイルとコマンドも登録できる
- 設定は実行ファイルと同じフォルダの `retac.settings.json` に即時保存（レジストリは使わない）

### キー割り当て

卓駆に付属していた FD 風・FILMTN 風などのキー配列は付属していません。キー配列をファイルに保存する機能も引き継いでいません。

カーソル移動などの固定キー（下の表を参照）を除き、ほぼすべての機能のキーを「キー割り当ての設定」で変更できます。既定のキー割り当ては、FILMTN 風の配列に作者の好みを加えた独自の配列です。

| 表示 | 新しいウィンドウ、ReTAC を完全に終了、コンテキストメニューの表示、フォルダのコンテキストメニューの表示、ドライブバー・アドレスバー・ブックマークバーの表示切り替え |
| クリップボード | コピー、切り取り、貼り付け、パスとファイル名をコピー、ファイル名のみコピー、`/` 区切りのパスをコピー |

## 外部ツール

エディタ、スクリプト、ターミナル、git コマンドなど、任意のプログラムを登録して ReTAC から起動できます。

- 登録数に上限はありません。登録したツールはメニューとポップアップメニューに並び、すべてにショートカットキーを割り当てられます。
- 引数にはマクロを書けます。カーソル位置やマークしたファイルのパス、カレントフォルダ、起動時に入力した文字列などを渡せます。
- マークしたファイルを 1 件ずつ順番に処理できます（外部ツールキュー）。
- 初期状態では、テキスト エディタ・テキスト ビューア（どちらも `notepad.exe`）とターミナル（`cmd.exe`）が登録されています。

**設定画面の説明、マクロの一覧、設定例（エディタ・Python・ターミナル・git）は [EXTERNAL_TOOLS.md](EXTERNAL_TOOLS.md) にまとめています。**

## インストール

発行済みの `ReTAC.exe`（.NET ランタイム不要の単一ファイル）を任意のフォルダに置いて起動します。設定ファイルは同じフォルダに作られます。

### 同梱の .NET ランタイムについて

配布する `ReTAC.exe` には、Microsoft の .NET ランタイムが含まれています。このランタイムには、ReTAC の MIT License ではなく、Microsoft .NET Library License（配布物の `DOTNET-LICENSE.txt`）が適用されます。ランタイムに含まれる第三者のソフトウェアの表示は `DOTNET-ThirdPartyNotices.txt` にあります。**ReTAC を使うことで、同梱のランタイムについてはこの使用許諾にも同意したものとみなします。**

自分でビルドする場合は .NET 10 SDK を使います。

```sh
dotnet publish src/ReTAC.App/ReTAC.App.csproj -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:EnableCompressionInSingleFile=true -o publish
```

## 困ったとき

- **左パネルのプレビューで、PDF など特定の種類だけが真っ白のままになる**
  ReTAC が異常終了したり強制終了されたりすると、Windows のプレビュー用のプロセス（`prevhost.exe`）が止まったまま残ることがあります。
  タスクマネージャーの「詳細」で `prevhost.exe` を終了するか、サインインし直してください。次にプレビューしたときに作り直されます。
  このプロセスはエクスプローラーなどと共有しているので、ReTAC は自分では終了させません。
